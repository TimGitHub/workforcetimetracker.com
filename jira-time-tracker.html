How auto-detection works on a Jira tab

Window-title parsing, no API token.

Step 1

Read the active tab title

On a Jira ticket the tab title is "PROJ-1234 Add login button - Jira" (Cloud / Server / Data Center all use this format). The app reads this on your machine.

Step 2

Parse out the ticket key + summary

The Standalone edition extracts "PROJ-1234" as the case identifier and "Add login button" as the description. The project code "PROJ" becomes the customer / project bucket.

Step 3

Pre-fill, you click Start

The customer field is filled with the project code, the case field with the ticket key + summary. Click Start. Optional auto-start fires the timer once the tab has been focused for the configured number of seconds.

Common Jira time-tracking questions

Does this connect to my Jira account?

No. The app reads the title of your active browser tab and parses out the Jira ticket key. It does not authenticate to Atlassian, does not store an API token, and does not call the Jira REST API. There is no app inside Jira to install.

Does it post worklogs back into Jira tickets?

Not in the current version. Time entries stay in local JSON files. You can export to Excel / CSV and bulk-paste worklog data into Jira yourself, or wait for the optional paid Connect add-on which is on the roadmap.

Will it work with Jira Cloud, Jira Server and Jira Data Center?

Yes. All three render the ticket key in the browser tab title (e.g. PROJ-1234 Add login button - Jira). The window-title parser handles all three the same way.

Does it work with Jira Service Management?

Yes. Service Management tickets follow the same key-prefix-and-number format (e.g. SUPP-789 Customer cannot log in). The parser detects them as part of the Standalone edition.

How does this compare to inside-Jira time trackers?

Different shape. Inside-Jira trackers live in your Atlassian instance and write back into Jira reports. This product is the desktop-side companion: it reads the Jira ticket key from your active browser tab (Cloud, Server or Data Center) and stores your time entries as plain JSON files on your own machine, ready to export to Excel / CSV / branded PDF invoice. Nothing is installed inside Jira, no API token is needed, and your time data never goes near Atlassian's cloud.

Can I track multiple Jira projects at once?

Yes. The app records each ticket as its own time entry, automatically grouped by project key (the prefix before the dash). Switching tabs between PROJ-1 and OPS-77 will be detected as switching customer/case automatically.
