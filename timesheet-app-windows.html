Why "portable .exe" matters

Reason 1

Locked-down corporate VM

The portable build does not require an installer. Your organisation may still require approval or block unsigned executables; follow its software and endpoint policies.

Reason 2

USB stick portable

Drop the .exe + data folder on a stick. Plug into any Windows machine. Same data, same licence. Useful for client-site visits.

Reason 3

VDI / Citrix friendly

Roams with the user profile if you put it under a roaming folder. No machine-specific install state to clean up.

Reason 4

One-folder uninstall

Back up your time-entry data before removing the portable app folder. If you enabled auto-start, disable it in Settings first.

Reason 5

Self-contained .NET 8

Bundled runtime - no separate .NET install required. Works on machines with no .NET, no chocolatey, no winget.

Reason 6

Updates without admin rights

Replace the .exe in place. Settings, customers and time entries persist (they live next to the .exe in JSON files, not in Program Files or AppData by default).

Common Windows questions

What Windows versions are supported?

Windows 10 and Windows 11, 64-bit. The build is self-contained .NET 8 - no .NET runtime install required. The .exe runs as is once unzipped.

Does it require administrator rights?

No. The portable .exe runs from any folder you can write to (Desktop, Documents, OneDrive, USB stick). Optional auto-start writes a single Run-key entry under your user hive (no machine-wide changes).

Which Windows download is available?

The current public download is a portable ZIP containing the Windows app. Extract it into a folder you can write to. This release is not code-signed; review the first-launch notes and your organisation's security policy before running it.

Does it run in the system tray?

Yes. Configurable: minimise-to-tray, hide on close, run on login. The tray icon shows the active timer state at a glance and lets you start / stop / switch customers without opening the main window.

What about SmartScreen on first launch?

Until the binary accumulates enough downloads to be Windows-trusted, SmartScreen may show a "More info" dialog on first launch. Click "More info" then "Run anyway". One-time per machine. We are working towards full code-signing as sales fund the EV certificate.
