Updates & changelog

Every release of Workforce Time Tracker. We ship small, focused changes that either improve time tracking or strengthen the promise that your data stays in your control instead of in a public cloud. We do not chase feature parity for its own sake.

⏱

What we will and won't ship

Will: better time tracking, better offline behaviour, better admin tooling, better local data formats. Won't: mandatory cloud accounts, vendor lock-in, telemetry, AI features that send your hours to a third-party LLM, or anything that makes "no cloud account" stop being literally true.

v1.7.6

May 2026 new fix polish

Smarter Settings validation, better invoice file names, friendlier locked-entry view.

New

  • Default folder for invoice PDFs can now be set independently from the export folder. Settings → Invoicing → “Invoice PDF folder”.
  • Customizable invoice file-name template. Tokens supported: {InvoiceNumber} {Customer} {WeekNumber} {WeekStart:yyyy-MM-dd} {Submitter}. Default is now INV-0001 - habit-1 - week 19 (2026-05-11) - Tim van Haren.pdf instead of the old opaque INV-0001_habit-1_20260511.pdf.

Fixed

  • Settings → Hourly Rate now blocks Save when “Enable hourly rate tracking” is on but the default rate is 0 or empty. Inline helper text turns red and the rate field is highlighted, so you fix the problem upfront instead of getting a surprise “Rate not configured” error later when exporting an invoice.
  • The locked time-entry view now explains why it is locked with a yellow banner (“This entry is locked because the week was submitted/approved. To make changes, ask your manager to reject the week.”) and hides the no-op Save button.

v1.7.5

May 2026 fix polish

Resume bug fixed, current time on screen, cleaner timer row, refresh after Submit Week.

Fixed

  • Status text + elapsed timer + wall-clock are now on a single row, freeing vertical space and making the tracker more glance-able.

v1.7.3

May 2026 fix polish

Quieter first launch and a friendlier Wrap-up-week button.

Fixed

  • No more "Refreshed: another device updated orgsettings.json" toast on first launch. The cold-start self-write window only covered five seconds; the first-run wizard's save of orgsettings.json happens later than that. v1.7.2

May 2026 polish legal

Calmer UI, clearer per-user licence reminder, and an EULA that finally spells out our right to revoke a key.

Added

  • Compact-mode transparency slider: drag the floating tracker from fully opaque down to 90% transparent so it fades into the background while you focus on the underlying CRM. Persists across launches.
  • Per-user licence reminder in the About window: an italic line under the LICENCE section explains in plain text that one licence covers one named user (or N seats for Company plans) and links to sales@workforcetimetracker.com for more seats.
  • Overflow menu in the main-window title bar consolidates Auto-tracking, Switch theme, Pin window, Export Excel/CSV, Settings, Admin console, and About behind a single ⋯ button. The header now shows only Approvals (manager-only), week calendar, compact toggle, and close.
  • EULA v1.1 with a new section 7 / 8 covering the Licensor's right to suspend or revoke a key on a good-faith determination of breach, with notice via email or the next app launch, no obligation to disclose detection methods, and an explicit carve-out preserving the user's locally stored JSON data files indefinitely. A 30-day dispute window and a Dutch consumer-rights savings clause are built in.

Improved

  • Soft transport buttons: Start, Pause, and Stop now use a neutral surface with a coloured icon (green play, amber pause, red stop) instead of solid coloured circles. Hover gently tints the background. Less visual noise on the main card.
  • Dark-themed customer combobox: the dropdown finally matches dark mode instead of opening a system-white pane.
  • Submit week button picks up the new PrimaryBtn accent style with rounded corners and hover/press states.
  • File-watcher self-write suppression: the app's own startup writes (settings.json seal updates, first-launch backfill) no longer trigger the misleading "another device updated this file" toast on cold start.

Fixed

  • Compact mode minimum window size reduced (240×120 instead of 280×100 floor) so the floating tracker can shrink further on small displays.

Notes

  • This release is Windows only. The macOS build remains at v1.4.0 alpha; Mac UI parity is tracked under Rule 11 exceptions in docs/parity-exceptions.md and lands in a Mac feature-catch-up release within the next two months.

v1.7.1

May 2026 privacy security

Manager approval workflow shipped end-to-end, telemetry checkbox removed, and licence keys now portable across keypairs.

Added

  • Pending Approvals window on Windows + macOS: a manager licence (role: manager) sees every submitted week from every user pointing at the same shared sync folder. One click approves; reject sends entries back to Draft with a reason.
  • Public-key file fallback for licence validation. Drop license_public.key in the data folder and the app accepts licences signed by an admin keypair without re-shipping the .exe. Useful when an organisation runs its own admin tool with its own keypair.
  • Manager-only header button in the main window, shown only when org settings have approval workflow enabled AND the loaded licence has the manager role.

Improved

  • The "Enable telemetry (not implemented)" checkbox in Settings was misleading - we never had telemetry. Removed entirely; PrivacyTelemetryEnabled is now hard-wired to false on save so Excel exports and the About screen always reflect reality.
  • Approval workflow toggle in the Admin window is no longer marked "coming soon" - it's wired all the way through.

Fixed

  • Admin tool: events fired during XAML InitializeComponent could NPE before the ledger was wired up. Added a _ready guard.
  • TimesheetService.ApproveWeekFor / RejectWeekFor now snapshot the entry list before iterating, so Update() mutations during the loop can no longer throw "collection was modified".

Security

  • Hardened the multi-device sync surface from v1.6: download URLs are now pinned to workforcetimetracker.com (HTTPS only) so a compromised version.json cannot redirect users to a malicious binary; CSV exports prefix formula characters with ' to block CSV injection in Excel/Numbers; lock-file display strings are sanitized of control codes and bidi marks before being rendered in toast banners.

v1.7.0

May 2026 major

Project budgets, daily billable goal, three sync hardenings.

Added

  • Project budgets: per-customer hour budget for fixed-fee work. Live progress bar warns at 80% and 100% so you stop discovering at month-end that you put 60 hours into a 40-hour contract.

v1.6.0

May 2026 major privacy

Multi-device sync via your own folder. No cloud account from us, ever.

Added

  • Multi-device sync via any folder you already replicate - Dropbox, OneDrive, iCloud Drive, SyncThing, NextCloud, an SMB share on your own NAS - your time entries follow you across devices. We never add a new vendor account, server, or third party. Settings → Use sync folder.
  • Live conflict awareness: when another device is using the sync folder, the new device sees a banner immediately on launch.
  • External-change reload: when the other device saves an entry, this one notices and refreshes automatically (or warns if you're mid-timer).
  • Provider auto-detect badge: the header shows SYNC: DROPBOX / SYNC: ONEDRIVE / etc. for confidence. We do this purely by inspecting the folder path; we never call any provider's API.
  • One-click revert: Settings → Reset to local. Sync folder data is never deleted, just unlinked.

Improved

  • All saves are atomic write-temp-then-rename, so a half-saved file on flaky Wi-Fi or a force-quit can't corrupt your week. Plus rolling .bak backups.

Highlights

What we are NOT building

policy

Saying no to the wrong features is how we keep the right ones laser-focused. None of these are coming, no matter how often a competitor announces them.

Off the roadmap on principle

  • Mandatory cloud accounts. No "sign up to sync". Multi-device sync uses YOUR folder, not ours.
  • Telemetry / analytics. The only outbound call is the optional version check.
  • AI features that ship your hours to a third-party LLM. We won't post window titles, descriptions, or client names to OpenAI / Anthropic / anyone.
  • Per-cloud-provider integrations (Toggl-style "100+ integrations"). Adds attack surface, lock-in, and complexity for marginal value over our offline auto-detect.
  • Server-side billing portal. Invoicing happens on YOUR machine, exporting a PDF you keep.
