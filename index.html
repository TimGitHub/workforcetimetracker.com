Features

Focused time tracking without the overhead

No mandatory cloud sync, no complex onboarding, no subscription dashboards. A single-purpose desktop application that does one thing well: tracking how you spend your billable hours.

One-click time tracking

Start and stop timers per client with a single click. Recent clients are remembered for instant switching between projects.

Professional Excel export

Export to a structured Excel workbook with raw entries, daily summaries, and weekly totals. Ready for client invoicing or internal reporting.

Live billable amount

Configure your hourly rate and see daily and weekly totals update in real-time as you work. Instant visibility into earned revenue.

Fully offline and private

All data is stored locally in a JSON file. No cloud account, no telemetry, no network calls. Your data stays on your machine.

Copy summaries to clipboard

One-click copy of today's time breakdown. Formatted and ready to paste into status reports, messages, or timesheets.

System tray with auto-start

Runs silently in the Windows system tray. Configure auto-start so tracking begins the moment your workday does.

Always-on-top mode

Pin the compact timer window above other applications. See elapsed time without switching context or searching for the app.

Edit entries after the fact

Adjust start and end times, rename clients, or correct mistakes on any entry. Full control over your recorded time data.

Team administration

Define organisation-wide client lists and configuration defaults. Distribute a shared settings file across your team.

FAQ

Frequently asked questions

Does this require an internet connection?

No. The application runs entirely offline. Licence validation uses local cryptographic verification with no server contact.

Where is data stored?

In the same folder as the executable, as a plain JSON file. You can back up, move, inspect, or delete it at any time.

Can I use this for my team?

Yes. Purchase multiple seats and use the admin console to distribute shared client lists and configuration defaults.

What happens when a licence expires?

A 14-day grace period begins. After that, the application displays a renewal notice but does not restrict access to your data.

Is this affiliated with Salesforce, Inc.?

No. Workforce Timetracker is an independent third-party product developed by a separate company. It is not developed, endorsed, or supported by Salesforce, Inc. "Salesforce" is a registered trademark of Salesforce, Inc.

Can I transfer to another machine?

Yes. Copy the executable and data file to the new machine. Your licence key is valid on any number of your own devices.

Is annual billing available?

Yes. Annual licences are available at EUR 48 per year (equivalent to EUR 4 per month). Contact us for an annual key.

Which operating systems are supported?

Windows 10 and Windows 11 (64-bit). A macOS version is under consideration based on user demand.
